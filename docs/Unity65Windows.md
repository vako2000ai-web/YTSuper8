# First Ride 2.0 — обновление и запуск на Windows

## Требования

- Windows 10/11 x64, Unity Hub, активная лицензия Unity Personal или другая подходящая лицензия.
- **Unity 6.5 / 6000.5.4f1**. Это версия проекта, а не Unity 5 и не Unity 6.0.
- Модуль **Windows Build Support (Mono)** для сборки .exe. Для Play Mode достаточно редактора.
- Интернет при первом открытии для Package Manager: Universal RP **17.5.0**, Unity UI **2.5.0** и их зависимости.
- Git для обновления; сервер Python для этой автономной демонстрации не требуется.

Используйте короткий путь, например **`C:\Work\YTSuper8`**. Глубоко вложенные папки могут вызвать `DirectoryNotFoundException` при импорте URP из-за ограничения длины путей в Windows/Mono.

## Вариант A: открыть готовый проект

1. Если старая версия уже есть, выйдите из Play Mode, сохраните собственные сцены и сделайте резервную копию. Закройте Unity, открывший эту же папку.
2. Загрузите обновлённый репозиторий с GitHub или выполните в PowerShell:

   ```powershell
   cd C:\Work
   git clone https://github.com/vako2000ai-web/YTSuper8.git
   ```

   Если это уже клон, сначала сохраните свои изменения коммитом или stash, затем:

   ```powershell
   cd C:\Work\YTSuper8
   git pull --ff-only
   ```

3. В Unity Hub выберите **Projects → Add → Add project from disk**. Укажите **`C:\Work\YTSuper8\UnityGame`**, а не корневую папку репозитория.
4. Откройте проект редактором **6000.5.4f1**. Дождитесь окончания импорта пакетов и компиляции. Не открывайте один проект двумя редакторами одновременно.
5. Откройте **Assets/Scenes/FirstRide.unity**. Если сцены или настроек ещё нет, выполните **Roller Coaster Heroes → Setup First Ride 2.0**. Команда создаёт сцену, URP renderer/pipeline, материал, защищающий Lit shader от удаления при сборке, и список сцен сборки.
6. Нажмите **Play**. В Game View выберите **16:9**, желательно **1920×1080**, включите звук. Сцена автоматически создаст трассу, парк, вагонетку, лиса, предметы и HUD.
7. Заезд идёт автоматически до финиша. Управлять скоростью вручную не нужно. Панель результатов показывает время, 62 собранные монеты и итоговые очки.

## Вариант B: обновить существующий URP-проект

1. Сделайте резервную копию своего проекта. Используйте Unity 6000.5.4f1 и Universal RP 17.5.0.
2. Найдите и удалите **старую копию** `FirstRideBootstrap.cs`, чтобы два загрузчика не создавали две игры. Не оставляйте старый скрипт под другим именем с тем же классом.
3. Скопируйте **все** файлы из `UnityGame/Assets/Scripts/` вместе с `.meta` в `Assets/Scripts/` вашего проекта. В новой версии загрузчик использует остальные классы — одного файла уже недостаточно.
4. Скопируйте `UnityGame/Assets/Editor/` вместе с `.meta` в `Assets/Editor/`. В Package Manager проверьте наличие Unity UI 2.5.0.
5. Создайте отдельную пустую сцену для демонстрации. Выполните **Roller Coaster Heroes → Setup First Ride 2.0**, затем откройте `Assets/Scenes/FirstRide.unity`.
6. Учтите: Setup назначает URP для графики и текущего уровня качества, меняет название приложения, цветовое пространство на Linear и **заменяет список сцен сборки** на FirstRide. Для большого проекта восстановите нужный список в Build Profiles после проверки.
7. Демонстрация создаёт собственные камеру, источник света и AudioListener, отключая существующие камеры, свет и слушатели на время Play Mode. Запускайте её в отдельной сцене.
8. Управление поддерживает старый Input Manager и новый Input System, если пакет Input System уже установлен. При Active Input Handling = Both используется новый Input System; дублирования нажатий нет. Добавлять Input System специально не требуется.

## Управление

| Клавиша | Действие |
|---|---|
| `R` | Полный перезапуск: дистанция, время, монеты, эффекты, звук, предметы и камера |
| `Space` | Пауза / продолжение, включая звук |
| `C` | Chase / Wide camera |
| `M` | Музыка вкл. / выкл.; эффекты остаются слышимыми |

Перед нажатием клавиш щёлкните по **Game View**. Камера плавно меняет FOV со скоростью, смотрит вперёд по трассе и облетает героя после финиша.

## Что реализовано

- Два непрерывных трубчатых красных рельса; поперечные шпалы, опорные фермы, диагональные связи и бетонные основания. Статические детали объединяются по материалам для уменьшения количества объектов отрисовки.
- Green Hills: длинный маршрут с холмами, поворотами, банковкой, стартовой/финишной арками, деревьями, холмами и туманом.
- Мультяшная вагонетка: четыре колеса с вращением по скорости, ступицы, шасси, округлый корпус, сиденье, поручень, декоративные полосы и фары.
- Процедурный лис FOX: моргание, движения головы, покачивание, хвост и шарф; поднятые руки при сборе/ускорении и празднование финиша. Это анимация частей модели кодом, без FBX, Animator Controller или сторонних ассетов.
- Золотые монеты с ободком и рельефом, бирюзовые ускорители с молнией, коралловые замедлители со знаком торможения, покачивание и вращение, повторно используемые искры при сборе.
- Англоязычный HUD 1920×1080 с масштабированием, временем, скоростью в **km/h**, монетами, счётом, статусом эффекта, прогрессом и финишной карточкой.
- HUD сохраняет композицию в центрированной рамке 16:9 и целиком помещается в окно при Free Aspect. Для трансляции по-прежнему рекомендуется вывод 1920×1080.
- Оригинальный процедурный музыкальный цикл **132 BPM**, бас и перкуссия; отдельные эффекты монеты, ускорения, торможения и финиша; тихий звук колёс. Аудиофайлы скачивать не требуется.
- Исходная формула: `max(0, 10000 - 50 × seconds) + 100 × coins`. Скорость ограничена 7–37 m/s. Один заезд содержит 70 предметов: **62 монеты, 5 ускорителей, 3 замедлителя** с фиксированным seed 20261013. Ускоритель даёт ×1.4 и моторный эффект 5 секунд, торможение ×0.7 и эффект 4 секунды; новый эффект заменяет предыдущий.

## Проверки в редакторе

1. Выполните **Roller Coaster Heroes → Validate gameplay**. При успехе Console содержит `FIRST_RIDE_VALIDATION_OK`, а `UnityGame/TestResults/gameplay.txt` — результаты.
2. Проверка охватывает повторяемость, границы трассы и скорости, все 70 предметов ровно один раз, формулу, завершение, неизменность результата после финиша, сброс и пересечение нескольких предметов за один шаг.
3. Для проверки реального Play Mode закройте редактор этого проекта и выполните из PowerShell:

   ```powershell
   $unity = 'C:\Program Files\Unity\Hub\Editor\6000.5.4f1\Editor\Unity.com'
   $project = 'C:\Work\YTSuper8\UnityGame'
   & $unity -batchmode -force-d3d11 -projectPath $project `
     -executeMethod FirstRide.Editor.FirstRideProject.PlaySmoke `
     -logFile "$project\playmode.log"
   $LASTEXITCODE
   ```

4. Не добавляйте `-quit` к PlaySmoke: проверка сама завершает Unity. Не используйте `-nographics`: проверка сохраняет реальные изображения камеры и HUD.
5. Успех: exit code 0, маркер `FIRST_RIDE_PLAYMODE_OK`, отчёт `TestResults/playmode.txt`. Выполняются два полных заезда с ускоренным временем, проверкой повторного результата, перезапуска, камеры, музыки, паузы, HUD и единственного слушателя. Изображения: `TestResults/first-ride-2.0.png`, `TestResults/first-ride-finish.png`.
6. Для обычного Play Mode время идёт с нормальной скоростью. Результаты автоматической проверки и сборки этого изменения перечислены в `docs/FirstRide2Validation.md`.

## Сборка .exe

1. В Unity Hub у установленного редактора выберите **Add modules → Windows Build Support (Mono)**, если модуль отсутствует.
2. В Unity выполните **Roller Coaster Heroes → Build Windows x64**. Результат: `UnityGame/Builds/Windows/RollerCoasterHeroes.exe` и соседние файлы.
3. Альтернатива из PowerShell, когда редактор проекта закрыт:

   ```powershell
   & $unity -batchmode -force-d3d11 -quit -projectPath $project `
     -executeMethod FirstRide.Editor.FirstRideProject.BuildWindows `
     -logFile "$project\build.log"
   ```

4. Запускайте .exe вместе со всей папкой сборки, включая `RollerCoasterHeroes_Data`, `UnityPlayer.dll` и остальные созданные файлы. Отдельного .exe недостаточно.
5. Для OBS используйте Game Capture этого приложения, вывод 1920×1080 и Desktop Audio либо захват аудио приложения. Сначала проверьте громкость музыки и эффектов на записи.

Проверку и сборку также можно выполнить из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\Test-FirstRide.ps1 -Build
```

Если редактор установлен в другом месте, передайте `-UnityEditor 'D:\Unity\6000.5.4f1\Editor\Unity.com'`. Скрипт не меняет Execution Policy системы; параметр выше действует только для этого процесса.

## Если что-то не работает

- **Красные ошибки компиляции:** дождитесь Package Manager; убедитесь, что перенесены все новые скрипты, а старый загрузчик удалён. Смотрите первую ошибку Console.
- **Розовые материалы:** запустите Setup; проверьте UniversalRenderPipelineAsset в Graphics и текущем Quality. Не выбирайте Built-in/Standard для материалов этой сцены.
- **Неверные красно-жёлтые цвета на старом GPU/драйвере:** запустите редактор с `-force-d3d11`. Setup назначает Direct3D 11 для Windows-сборки; на проверенном Intel Iris Plus старый Direct3D 12 отображал материалы некорректно.
- **Пакет не загружается:** проверьте доступ Hub/Unity к packages.unity.com и вход в Hub. Сохраняйте `Packages/manifest.json` и `packages-lock.json` из репозитория.
- **Пустая Scene View до Play:** окружение создаётся во время запуска; смотрите Game View. Сама сцена содержит загрузчик.
- **Нет звука:** выйдите из паузы, проверьте M, Mute Audio в Game View и микшер Windows. M отключает только музыку.
- **Нет реакции на клавиши:** дайте Game View фокус; проверьте Active Input Handling в Player Settings.
- **Batch mode ждёт лицензию:** откройте Unity Hub обычным пользователем и активируйте лицензию; не запускайте второй редактор на той же папке.
- **Низкий FPS:** уменьшите разрешение Game View, используйте 1280×720, сократите Shadow Distance в `FirstRideURP.asset`. Итоговую производительность проверяйте в .exe.

## Границы этой версии

Это автономный First Ride: один герой, один маршрут и повторяемый заезд. Турнир 10 героев × 3 раунда, DonationAlerts, сохранение результатов, управление OBS, Blender/FBX-ассеты и полноценный AudioMixer остаются следующими этапами. Процедурные примитивы и анимации уже работают как единая игровая модель, но не заменяют финальную художественную проработку. Субъективное качество звука и производительность на другом ПК следует проверить вручную.

Документация Unity: [URP в Unity 6](https://docs.unity.com/en-us/engine/6000.3/manual/render-pipelines/universal-render-pipeline), [настройки качества URP 6.5](https://docs.unity.com/en-us/engine/6000.5/manual/render-pipelines/universal-render-pipeline/urp-quality-settings).
