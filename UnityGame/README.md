# Unity Game — Milestone 1

Copy `Assets/Scripts/FirstRideBootstrap.cs` into an empty Unity 6 URP project. Enter Play mode and the prototype self-constructs.

Included: generated track, cart and placeholder fox, 70 seeded pickups, moving camera, arcade slope physics, score HUD, synthesized cheerful melody, keyboard controls.

**Limitations:** source not yet verified by compiling in Unity; no real FBX models, Unity Splines authoring, persistent scores, live DonationAlerts, effects queue or tournament mode. The track is a procedural approximation, not a complete production roller coaster. Add Unity project files after establishing an editor version and validating the prototype.
